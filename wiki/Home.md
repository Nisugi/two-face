## Quick Commands

```bash
# Start with Lich
two-face --host 127.0.0.1 --port 8000

# Start with direct eAccess
two-face --direct --account USER --password PASS --game prime --character NAME

# Show help
two-face --help
```

## File Locations

| Platform | Config Directory |
